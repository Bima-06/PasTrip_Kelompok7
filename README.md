# PasTrip

**Informasi wisata Nusantara dengan biaya yang transparan.**

PasTrip adalah website statis untuk membantu merencanakan perjalanan wisata. Setiap destinasi menampilkan rincian biaya perkiraan (tiket, parkir, biaya tambahan, dan total per orang), fasilitas, akses transportasi, serta ulasan pengunjung, sehingga pengunjung bisa membandingkan tempat wisata sebelum berangkat.

## Fitur

- Pencarian destinasi berdasarkan nama, lokasi, atau kategori
- Kategori wisata: Wisata Alam, Wisata Budaya, Wisata Kuliner, Petualangan, Pantai, dan Religi
- Filter berdasarkan rentang harga tiket, kategori, dan fasilitas
- Pengurutan berdasarkan popularitas, rating, tiket termurah, atau total biaya terendah
- Halaman detail dengan galeri foto dan video, fasilitas, akses, lokasi, dan ulasan
- Tampilan responsif untuk HP, tablet, dan desktop

## Teknologi

- HTML5, CSS3, dan JavaScript
- Bootstrap 5.3.3
- Google Fonts (Inter)
