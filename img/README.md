## Video (opsional, hanya Parangtritis)

Letakkan satu video pendek dengan nama `pantai-parangtritis.mp4` di folder ini.
- Durasi 10-15 detik, 720p, ukuran maksimal sekitar 3 MB (kompres dengan HandBrake atau handbrake.fr / ezgif.com/video-to-mp4).
- Sumber berlisensi bebas: Pexels, Pixabay, Wikimedia Commons. Catat kreditnya.
- Sampul video memakai `pantai-parangtritis-3.webp` bila ada.
- Video baru dimuat saat thumbnail diklik, jadi halaman tetap ringan.
- Selama file belum ada, klik thumbnail Video menampilkan tulisan "Video belum tersedia".
- Untuk destinasi lain: tambahkan `video: 'img/nama.mp4'` di js/data.js. Tanpa field itu, thumbnail ketiga tampil sebagai foto biasa.
